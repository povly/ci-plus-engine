# Лямбды

Лямбда — безымянная функция, написанная прямо в месте использования.

```cpp
// как используется в движке (EventDispatcher)
dispatcher.Dispatch<WindowResizeEvent>([&](WindowResizeEvent& e) {
  POVLY_CORE_TRACE(e);
  return true;              // «обработано»
});
```

Разбор записи:

```cpp
[&](WindowResizeEvent& e) { POVLY_CORE_TRACE(e); return true; }
 │  │                     │
 │  │                     └ тело — обычный код
 │  └ параметры, как у функции
 └ захват: что из окружения видно внутри
```

## Захват

```cpp
[&]     // всё окружение по ссылке — можно читать и менять
[=]     // всё по копии — читаешь снимок значений на момент создания
[x, &y] // выборочно: x копией, y ссылкой
[]      // ничего не захватывать (защита от случайных зависимостей)
```

`[&]` — самый частый в коротких колбэках, как в диспетчере: лямбда живёт
строку-другую, всё окружение доступно.

## Лямбда = объект

Компилятор превращает лямбду в маленький объект-функтор (класс с operator()).
Поэтому она проходит на место параметра `const F& func` в шаблоне Dispatch —
`F` выводится как тип этого объекта.

## Было бы без лямбды

Пришлось бы объявить функцию/структуру отдельно и передать по имени:

```cpp
bool OnResize(WindowResizeEvent& e) { POVLY_CORE_TRACE(e); return true; }
...
dispatcher.Dispatch<WindowResizeEvent>(&OnResize);   // или так, но код далеко от вызова
```

Лямбда держит обработчик рядом с местом, где он нужен.
