# C++ конспект по коду движка

Все примеры взяты из этого репозитория (`src/engine`, `src/sandbox`).
Каждая папка — отдельная тема, файлы внутри — по порядку.

## Порядок чтения

| № | Папка | Про что |
|---|-------|---------|
| 1 | `01-oop/` | Классы, конструкторы, наследование, «контракт», static |
| 2 | `02-types/` | `enum` vs `enum class` vs `enum : T`, битовые маски, псевдонимы типов |
| 3 | `03-memory/` | Ссылки, указатели, const, умные указатели |
| 4 | `04-generic/` | Шаблоны и лямбды |
| 5 | `05-engine/` | Как устроен сам движок: запуск, события, логгер |
| 6 | `06-organization/` | Макросы, пространства имён, .h/.cpp, разное |
| 7 | `07-old-vs-new/` | «Как писали раньше и почему сейчас так» — сравнение старого и современного C++ |

## Как пользоваться

- Читай по одному файлу за раз, потом находи этот же код в `src/` — там всё ровно так, как описано.
- Встретил непонятное слово — ищи в README этой папки или в соседних файлах.
- Файл `07-old-vs-new/README.md` полезно перечитывать по мере роста опыта: сначала «что», потом «почему именно так».
