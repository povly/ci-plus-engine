# Разное, что встречается в коде

## auto — выведи тип сам

```cpp
auto app = Povly::CreateApplication();   // тип: std::unique_ptr<Application>
```

Компилятор смотрит на правую часть и подставляет тип. Писать стоит, когда тип
очевиден из правой части или длинный (`std::shared_ptr<spdlog::logger>`).
Не стоит — когда тип важен для понимания, а справа его не видно.

## std::stringstream — собрать строку по кускам

```cpp
// ApplicationEvent.h
std::string ToString() const override {
  std::stringstream ss;
  ss << "WindowResizeEvent: " << m_Width << ", " << m_Height;
  return ss.str();          // ss.str() → готовая std::string
}
```

## nullptr, а не NULL — короткое напоминание

`nullptr` — настоящая константа «указатель в никуда». `NULL` — унаследованный
из C макрос, по сути `0`, из-за чего мог путаться с целым числом.

## Цена виртуальных вызовов

Виртуальный вызов — один лишний поход по таблице указателей (vtable). Для
событий и логгера это копейки; виртуальность тут — правильный инструмент.
**Не оптимизируй раньше времени** — сначала измерь.

## Неиспользуемые параметры

Сборка показывает предупреждения на `int main(int argc, char** argv)` в
EntryPoint.h: аргументы не используются. Современное решение — пометить:

```cpp
int main(int [[maybe_unused]] argc, char [[maybe_unused]]** argv)
```

(предупреждения в проекте остались — можно поправить, когда будешь готов.)
