# Ссылки, указатели, const

## Ссылка — псевдоним объекта

```cpp
WindowResizeEvent real(1280, 720);
WindowResizeEvent& alias = real;   // alias — ТОТ ЖЕ объект, второе имя
alias.GetWidth();                  // 1280
```

- Не бывает «пустой» ссылки — всегда на что-то указывает.
- Привязывается один раз, перенаправить нельзя.
- Разыменовывать не нужно — пишешь как обычную переменную.

## Указатель — адрес

```cpp
WindowResizeEvent* ptr = &real;   // & = «взять адрес»
ptr->GetWidth();                  // -> = доступ через указатель
(*ptr).GetWidth();                // то же самое, длиннее
```

- Может быть `nullptr` («ни на что») — это и плюс (пустое значение), и минус
  (можно забыть проверить).
- Можно переназначать на другой объект.

В движке указатели почти не встречаются в чистом виде — используются умные
(см. `02-smart-pointers.md`). Ссылки — повсюду.

## const

Три главных места:

```cpp
unsigned int GetWidth() const { return m_Width; }
//        ^^^^^^ после метода: «не изменю объект». Такие методы видят только
//               другие const-методы. У геттеров — всегда.

void Print(const std::string& text);
//           ^^^^^ читаю, но не меняю — и без копирования

const float gravity = -9.8f;
//    ^^^^^ переменная только для чтения
```

**const T&** — самый частый способ передать объект в функцию: дёшево (копии нет)
и безопасно (изменить не дадут). Обратно из функций большие объекты тоже
возвращают по ссылке/const-ссылке, когда копировать дорого.

## Правило

Пиши `const` везде, где можешь. Ошибка «попытка изменить const» на этапе
компиляции лучше, чем испорченные данные во время работы.
