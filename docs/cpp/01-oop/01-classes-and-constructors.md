# Классы: конструктор, поля, методы

Пример — `src/engine/Events/ApplicationEvent.h`:

```cpp
class WindowResizeEvent : public Event {
 public:
  WindowResizeEvent(unsigned int width, unsigned int height)   // конструктор
      : m_Width(width), m_Height(height) {}                    // список инициализации
  unsigned int GetWidth() const { return m_Width; }            // метод (геттер)
 private:
  unsigned int m_Width, m_Height;                              // поля
};
```

## Конструктор

Функция, которая вызывается при создании объекта. Имя = имя класса,
возвращаемого типа нет.

```cpp
WindowResizeEvent e(1280, 720);   // вызов: width=1280 уйдёт в m_Width, height=720 в m_Height
```

## Список инициализации

Часть после `:` — поля заполняются **до** входа в тело конструктора:

```cpp
: m_Width(width), m_Height(height) {}   // тело пустое — всё сделано списком
```

Это предпочтительный способ (для членов-классов ещё и более эффективный —
поле сразу строится из значения, а не строится пустым и потом присваивается).

Если конструктору нечего делать — можно попросить компилятор сделать
обычный пустой:

```cpp
WindowCloseEvent() = default;
```

## Деструктор

`~ИмяКласса()` — вызывается при уничтожении объекта. Освобождает ресурсы.

```cpp
class Application {
 public:
  Application();
  virtual ~Application();   // virtual — важно! почему, см. 02-inheritance
};
```

В движке: `Application::Application() {}` и `Application::~Application() {}` —
пока пустые, заготовки на будущее.

## Перегрузка

Несколько функций с одним именем, но разными параметрами. Компилятор выбирает
по аргументам. (Конструкторы — самый частый случай перегрузки.)

## Уровни доступа

- `private:` — видно только самому классу (по умолчанию в `class`)
- `protected:` — классу и наследникам
- `public:` — всем

Префикс `m_` в `m_Width` — соглашение по коду: «это поле класса» (member).

## Методы

`GetWidth()` — обычная функция внутри класса, работает с полями своего объекта.
`const` после скобок — обещание «объект не изменю» (подробнее — `03-memory/01`).
